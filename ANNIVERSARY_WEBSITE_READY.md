## ⚡ 3 LANGKAH CEPAT UNTUK MULAI

### LANGKAH 1: Tambahkan Foto 
```
1. Buka folder: public/photos/
2. Copy 5+ foto ke sini (format: JPG/PNG)
3. Best: foto persegi 600x600px atau lebih
```

### LANGKAH 2: Update Nama Foto di HTML
```
1. Buka: public/index.html dengan text editor (Notepad/VS Code)
2. Cari: <!-- PETUNJUK PENGGANTIAN GAMBAR -->
3. Ganti setiap link foto dari URL ke: photos/photo1.jpg, photos/photo2.jpg, dll
4. PENTING: Update 10 foto total (5 asli + 5 duplikasi)
5. Save file
```

### LANGKAH 3: Tambahkan Musik
```
1. Buka folder: public/music/
2. Copy file: janjisuci.mp3 ke sini
3. Format: MP3 (sangat recommended)
4. Durasi: 3-5 menit
```

## 🎯 CARA MEMBUKA WEBSITE

### Metode 1: Direct File (Paling Mudah)
```
1. Buka folder: /vercel/share/v0-project/public/
2. Double-click: index.html
3. Website akan terbuka di browser favorit Anda
4. Klik tombol "Buka Kenangan Kita" untuk lihat galeri
```

### Metode 2: Drag ke Browser
```
1. Buka file manager
2. Drag file: public/index.html ke browser window
3. Selesai!
```

### Metode 3: Via Terminal/Command Prompt
```
cd /vercel/share/v0-project/public
python -m http.server 8000
# Buka: http://localhost:8000/index.html
```

## 💡 TIPS SUKSES

1. **Foto terbaik = Website lebih menarik**
   - Gunakan foto berkualitas tinggi
   - Persegi (1:1 ratio) paling ideal
   - Pencahayaan konsisten

2. **Musik yang tepat = Emosi yang tepat**
   - Pilih lagu yang bermakna
   - Volume balance jangan terlalu keras
   - Format MP3 untuk kompatibilitas terbaik

3. **Urutan cerita**
   - Susun foto dari masa lalu ke sekarang
   - Atau mix dengan momen-momen spesial
   - Jangan random agar lebih bermakna

4. **Test dulu sebelum show**
   - Buka di browser favorit Anda
   - Test di mobile juga
   - Pastikan musik & foto semua jalan
