# 🎵 Folder Musik

Letakkan file musik Anda di folder ini.

## Cara Menambahkan Musik

1. **Download atau siapkan file musik**
   - File: `janjisuci.mp3`
   - Format: MP3 (sangat disarankan)
   - Durasi: 3-5 menit (ideal untuk galeri)
   - Ukuran: Kurang dari 10MB

2. **Copy file ke folder ini**
   - Letakkan `janjisuci.mp3` di sini
   - Atau file musik lainnya dengan nama yang sama

3. **Musik akan otomatis dimainkan**
   - Saat Anda klik tombol "Buka Kenangan Kita"
   - Volume otomatis di-set ke 50%

## 🎹 Format File Musik yang Didukung

- ✅ MP3 (paling kompatibel)
- ✅ WAV
- ✅ OGG
- ✅ M4A / AAC

## 🔧 Shortcut Keyboard

- Tekan tombol **M** untuk mute/unmute musik
- Musik akan terus bermain sambil Anda menikmati galeri

## 💾 Tips

- Simpan file musik original di tempat aman
- Gunakan musik royalty-free untuk keamanan hak cipta
- Ukuran file yang lebih kecil = loading lebih cepat

---

**Catatan:** Jika file musik tidak ditemukan, website tetap akan berfungsi normal, hanya tanpa musik latar.
